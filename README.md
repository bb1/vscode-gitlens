# Offline GitLense

Offline GitLense is a local-Git-focused VS Code extension fork.

It provides local Git history, blame annotations, hovers, CodeLens, status bar blame, patches, worktrees, comparisons, interactive rebase, Commit Details, Settings, Commit Graph, direct host providers, and a local Git MCP server.
